# 📝 To-Do List Web Application

A simple and responsive **To-Do List Web Application** developed as **Task 4** of my **SkillCraft Technology Web Development Internship**.

## 🚀 Features

* ➕ Add new tasks
* 📋 Organize tasks into categories
* ✅ Mark tasks as completed
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* 📅 Set task date
* ⏰ Set task time
* 🔍 Filter tasks by All, Pending, and Completed
* 📊 View task statistics
* 💾 Save tasks using LocalStorage
* 📱 Responsive user-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser LocalStorage

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your web browser.
4. Add and manage your tasks.

## 🎯 Task Objective

The objective of this task is to develop a basic To-Do application that allows users to add, organize, edit, complete, delete, and schedule tasks with a date and time.
